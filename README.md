# 🎬 Anime Vibe Check

A dynamic web application where anime fans can rate their favorite movies, vote on iconic soundtrack songs, and see live community leaderboards. 

## ✨ Features

* **Movie Ratings:** Rate feature films with an interactive star system.
* **Soundtrack Voting:** Upvote or downvote top anime openings (OPs) and endings (EDs).
* **Live Leaderboards:** Real-time rankings of the highest-rated media.
* **User Profiles:** Track your personal voting history and favorites list.
* **Search & Filter:** Easily find titles by genre, studio, or release year.
